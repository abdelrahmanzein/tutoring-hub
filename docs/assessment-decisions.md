# Assessment feature: decision log

Decisions from the first real run (AA HL Functions Quiz, Oct 2026). These are kept so they're not re-litigated.

| # | Decision | Rejected alternatives | Why |
|---|---|---|---|
| 1 | Annotations go ON the page in a handwriting font | Side-margin annotation column | Must look like a real examiner's marking in Zein's hand |
| 2 | No annotation may overlap another (verified, 0 overlaps) | "Mostly clear" placement | Overlaps made marks unreadable |
| 3 | Grade out of a cap C while A > C marks are available | Grade out of A | Choice of questions, teacher flexibility, exam pacing (see CLAUDE.md) |
| 4 | **Option C boundaries:** cap at C; [max(0, μ−3σ), C] in 7 equal bands; level 7 open | (A) uncapped μ±3σ: level 7 started at 58 > 40, which is nonsense. (B) μ±1σ bands: too narrow. (D) μ±2σ clipped: unstable top. Fixed IB-style percentages: ignores the class | The top must equal 100% of the cap; the bottom follows class spread |
| 5 | Level 7 has no upper limit; show raw e.g. 51/40 = 127.5% | Clip at 40 | Rewards attempting extras |
| 6 | Unattempted or missing questions: neutral note only | Flag or ask for missing pages | Expected by design |
| 7 | Cover: 3 strengths; ALL weaknesses; Next step = re-solve incorrect questions with the markscheme after each | Generic 2–3 improvements; practice-question suggestion | Zein's teaching routine |
| 8 | Personalised notes and practice deferred | Include now | Scope; revisit after v1 |
| 9 | Always produce the class report + one folder | Report optional | Zein uses the report every time |
| 10 | Disorganised script: one general comment on the cover | Comment on every page | Less noise |
| 11 | Integrity: list concrete signals, never accuse | Verdicts | IB practice |
| 12 | Reference font Noteworthy (Apple). The app needs an OFL alternative or the teacher's own font | Bradley Hand (couldn't be staged); Chalkboard | Licence; "M1" in Noteworthy can look like "MI" |
| 13 | AI key only in the Cloudflare Worker | Key in the client | The repo and site are public |

Calibration rulings from moderation are listed in `CLAUDE.md`.
